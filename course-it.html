Programme overview

What you'll learn.

The Diploma in Information Technology builds working IT professionals — not lecture-hall theorists. Across twelve months you will write code that ships, configure networks that route traffic, secure systems against real attack patterns, and deploy applications to the cloud.

Every module ends in a portfolio artefact. By graduation you'll have built a multi-page web application, configured a small-office network, audited a sample system for vulnerabilities, and shipped a containerized service to AWS or Azure.

Key learning outcomes

  • Build full-stack web applications using modern frameworks and version control
  • Design, query and administer relational databases in production-realistic scenarios
  • Configure routers, switches, VLANs and basic firewall policies
  • Identify and remediate common application and infrastructure vulnerabilities
  • Deploy and operate containerized services on AWS or Azure
  • Apply software engineering practices: testing, CI/CD, code review, agile delivery

Course curriculum

The programme is structured around 10 core modules delivered across two semesters with continuous assessment and a capstone project.

01 Programming Fundamentals (Python) 5 weeks
Variables, control flow, data structures, functions and OOP. Project: a CLI utility published to your GitHub portfolio.
02 Database Systems & SQL 4 weeks
Relational design, normalization, joins, transactions, and indexing using PostgreSQL.
03 Web Development (Front-end) 4 weeks
HTML, CSS, responsive design, and modern JavaScript including a brief React introduction.
04 Web Development (Back-end) 4 weeks
REST APIs with Node.js / Express, authentication, deployment, and database integration.
05 Networking Essentials 4 weeks
OSI model, TCP/IP, routing and switching, VLANs, and a Cisco Packet Tracer lab series.
06 Operating Systems & Linux 3 weeks
Linux file systems, shell scripting, process management, and basic system administration.
07 Cybersecurity Essentials 4 weeks
Common attack vectors, OWASP Top 10, secure coding practices, and a basic penetration-testing lab.
08 Cloud Computing 4 weeks
AWS and Azure fundamentals, IaaS vs PaaS vs SaaS, deploying a containerized service end-to-end.
09 Software Engineering Practices 3 weeks
Version control with Git, testing fundamentals, CI/CD pipelines, agile rituals.
10 Capstone IT Project 7 weeks
A team-built, deployed application with documentation, defended before an industry panel.

Career outcomes

Graduates progress into roles across local and international employers — and many continue into our partnered international bachelor's degrees.

Software Developer

Build and maintain web or mobile applications across the stack.

Web Developer

Design, build and maintain client websites and applications.

Network Administrator

Operate and secure organizational networks and infrastructure.

IT Support Engineer

First and second-line support across hardware, software and cloud.

Cybersecurity Analyst

Monitor, investigate and respond to security events.

Cloud / DevOps Engineer

Operate cloud platforms, CI/CD and infrastructure-as-code.

Database Administrator

Design, optimize and safeguard production databases.

QA / Test Engineer

Build automated test suites and quality processes.

Junior Data Analyst

Query, visualize and report on operational data.

Eligibility & entry requirements

  • GCE Advanced Level (3 passes, any stream) or equivalent
  • GCE O/L credit pass in Mathematics and English
  • Basic computer literacy (no prior programming required)
  • Mature applicants (23+) considered with relevant IT experience
